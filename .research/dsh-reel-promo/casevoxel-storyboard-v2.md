## 3. 鲸鱼跳跃动作规范（所有跳跃共用）

| 阶段 | 时长 | 做法 |
| --- | --- | --- |
| 蓄力 | 8–12f | 身体下压 12–18%、尾巴抬起 10°，位置下沉 0.05 单位 |
| 起跳 | 4f | 快速伸展、旋转 -8° |
| 空中 | 16–22f | 抛物线（sin 曲线），带轻微前倾；身体拉长 5% |
| 落地 | 3f | squash 15–20%，接触阴影出现，按钮 pressed |
| 回弹 | 6–8f | 恢复 + 轻微 overshoot；鲸鱼退开半步，露出按钮状态 |
| 接触阴影 | 全程 | 椭圆 shadow 贴在落点，随高度缩放/变淡 |

尺寸规则：
- hero 鲸鱼：世界宽 ~5 单位
- UI 场景鲸鱼：世界宽 ~1.0–1.2 单位（画面宽 6–7%）
- 从 hero 到 UI 必须**连续缩**，不能在切点突变

## 4. 实现方案

### 方案 A（推荐）：真 3D 连续空间

- 新建 `Journey3D` 场景，覆盖 90–765f（3.0–25.5s）：
  - 用 `ThreeCanvas` + 正交/透视相机；UI 截图作为 textured plane 放进 3D 场景（终端、DSH 主窗、插件页、结果卡、侧栏）。
  - 相机路径写成 `cameraAt(f)` 纯函数：俯视 → 推近插件 → 推近搜索 → 推安装 → 横移侧栏 → 拉回。
  - 鲸鱼用现有 `WhaleVoxel`（idle 模式）放进同一个场景，用 group 的 position/scale/rotation 做跳跃；加接触阴影 mesh。
  - 页面切换 = 两个 plane 在同一位置交叉淡入淡出 + 相机推进（push-through），不是切场景。
  - 按钮按下 = 在 UI 图上叠一个 pressed 状态 sprite/mesh（下压/高光/波纹）。
- 片尾卡可以是 2D HTML overlay（不影响 3D 镜头），或 3D 文字平面。

### 方案 B（备选）：2.5D

- 保留 HTML UI，但：
  - 鲸鱼换成透明 3D 层（ThreeCanvas 叠加），按 UI 透视对齐；
  - 页面切换用 CSS 3D transform + 遮罩做 push-through；
  - 跳跃用 3D 鲸鱼（不是贴图）做 CSS 3D 空间里的运动。
- 工作量小于 A，但空间感仍不如 A；如果 A 风险大，先用 B 过渡。

### 需要的素材

- 终端（现有 HTML）
- 干净 DSH 主界面截图（已有 `dsh-main-clean.png`）
- 插件发现页截图（已有 `dsh-plugin-page.png`）
