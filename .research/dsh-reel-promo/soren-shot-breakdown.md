### 这段的关键做法（复用到我们的片子）

1. **图标是 3D 实体**：圆角方块、厚度、地面软阴影、反光；不是 HTML 图标。
2. **低机位 + 浅景深**：相机贴近地面（y≈1.2），焦点在图标/鲸鱼，前后景虚化。
3. **鲸鱼和图标同尺度**：一开始鲸鱼和图标差不多大，甚至更大；靠近窗口后，相机推进让鲸鱼相对变小。
4. **按压反馈**：图标下沉 + 光晕 + 波纹 + 鲸鱼 squash + 接触阴影，五个一起才像"按了"。
5. **窗口从图标上方升起**：plane 从图标后下方升到画面中央，相机同时抬升；不是"弹窗"。
6. **图标变 Dock**：窗口展开后，原图标行留在画面底部作为 Favorites，保持空间连续。
7. **相机是"跟鲸鱼"的**：鲸鱼走/跳，相机跟着推进；没有为了展示 UI 而单独切镜头。

## 三、全片为什么成立（6 条）

1. **一个空间**：桌面 → 地面图标 → App 窗口 → Profile → 片尾卡，全部在同一个 3D 世界里；没有切场景。
2. **一只鲸鱼**：从终端里"生"出来，一路是观众的唯一向导；它的位置就是观众注意力。
3. **运动匹配**：每次镜头移动都由鲸鱼的运动触发（跳、走、点），不是无缘无故推镜头。
4. **尺度递进**：鲸鱼从"比终端还大"→"和图标同大"→"在 App 里很小"，空间越进越深，但鲸鱼始终是锚点。
5. **UI 是物理对象**：图标有厚度、窗口有透视、按钮有按压、搜索栏发光；观众相信鲸鱼真的在"操作"。
6. **没有字幕**：信息全在 UI 和片尾卡；不打断沉浸感。

## 四、可直接套用的公式

- **0–2s**：给一个"终端/入口"，让观众知道从哪开始。
- **2–4s**：主角从入口"生"出来（拼合/出现），入口保留。
- **4–6s**：主角跳到第一个"物理 UI"（图标/按钮），按压反馈。
- **6–10s**：UI 原地展开/镜头推进，主角跟着进 UI。
- **10–14s**：主角在 UI 里完成一个任务（搜索/点击/关注）。
- **14–17s**：镜头拉回，片尾卡在同一个空间浮出。
- **17–19s**：hold，最后一句 CTA。
