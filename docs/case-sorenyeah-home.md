# Case: Sorenyeah home film · 30 s

A 38-second film for **[sorenyeah.com](https://sorenyeah.com/)** — Soren's personal homepage — built with
this repo's Remotion studio. It opens with the user's whale mascot rebuilt in 3D from their reference film
`Soren_DeepSeek_whale.mp4` (terminal → voxel whale assembles → hops onto the Sorenyeah app icon → the real
homepage rises out of the dock), then tours the live site. It is the first case in the repo whose subject is
a **website** rather than a DSH plugin, and the first one whose footage is the live site's own pixels.

- Output: 1920×1080 / 30 fps / 38.0 s, H.264 + AAC, `studio/out/sorenyeah-home.mp4`
- Cover: 1080×1440 poster, `studio/out/sorenyeah-poster.png` · 16:9 cover still, `studio/out/sorenyeah-cover.png`
- Delivered copy (with stills): `../sorenyeah-film/output/`
- Code: `studio/src/sorenyeah/` · assets: `studio/public/sorenyeah/` · audio script: `studio/scripts/make_home_audio.py`
- Rendered 2026-11-08. Not part of a campaign; no narration, no invented metrics.

Score grid: 120 BPM, 19 bars (beat = 15 frames, bar = 60 frames), so every scene cut
(240 / 330 / 450 / 540 / 690 / 810 / 960) sits exactly on a beat of `music-bed-home38.wav`
(profile `38` of `make_music_v2.py`).

## Audio

`studio/scripts/make_home_audio.py` runs the v2 synthesis engine with this film's timeline:

```sh
python3 studio/scripts/make_home_audio.py
ffmpeg -y -i studio/public/sorenyeah/audio/mix.wav -b:a 192k \
       studio/public/sorenyeah/audio/preview-mix.mp3
```

- `SOUND_EVENTS` lives in `studio/src/sorenyeah/timeline.ts` and is parsed at run time (single source of truth).
- 64 events on 38 s: typing ticks, riser into the assembly, `landBig` on the assembly land and the icon
  landing, `spout`, `window` as the homepage rises, a hit on every cut, key clicks for the track list;
  the SFX bus is ducked into the bed.
- Measured on the final master: −20.6 LUFS RMS in the mix bus, −1.5 dBFS peak, 48 kHz stereo.

## Render

```sh
# from the repo root
npm run home:audio
npm run home:render       # studio/out/sorenyeah-home.mp4
npm run home:poster       # studio/out/sorenyeah-poster.png (1080×1440)
```

or directly:

```sh
cd studio
node_modules/.bin/remotion render src/sorenyeah/entry.tsx SorenyeahHome out/sorenyeah-home.mp4 --codec h264 --crf 16
node_modules/.bin/remotion still  src/sorenyeah/entry.tsx SorenyeahPoster out/sorenyeah-poster.png --frame=0
node_modules/.bin/remotion still  src/sorenyeah/entry.tsx SorenyeahHome out/frame.png --frame=60
```

## Known limits

- **One aspect ratio**: 16:9 only. A 9:16 cut would need a re-layout of C0 (the 3D dock is 16:9 native) and
  of C3–C6 (the grid and the two-column music/writing scene do not fold down on their own).
- **C0 is a rebuild, not the reference footage**: the grammar and the whale model are faithfully reused, the
  camera/lighting/composition are ours; the reference's X-app sequence is replaced by "the site opens".
- **No narration and no captions track**: the film is designed to read muted, like the site.
- **The music is a synth bed in the repo's Am–F–C–G world** (profile `38`), not the user's own track. Swapping
  in an excerpt of *再往前一步* would need a re-cut or a tempo-matched edit; the picture is on a 120 BPM grid.
- **Screenshots are from 2026-11-08.** If the site changes, re-capture `shots/` and re-check C2's crops.
- C2 is the only scene made of live-site pixels; C3–C6 rebuild the sections in React from the site's own
  images and copy. That is deliberate (crisper motion, real UI in the reveal), but it means C3–C6 must be
  re-checked against the site after a redesign.
