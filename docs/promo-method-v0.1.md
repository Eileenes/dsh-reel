# 插件真机宣传片方法 v0.1

> 适用：给任意 DSH 插件做一条 **30 秒以内、以真实界面为主** 的宣传片。
> 首个案例：Better Sidebar（见 [`case-better-sidebar-v0.1.md`](./case-better-sidebar-v0.1.md)）。

## 0. 三条原则

1. **先读插件，再写分镜**：功能、tab、按钮、真实界面状态从 README/源码/官方截图里来，不凭空画。
2. **一镜到底的语法**：同一段里镜头只做一次连续运动；鲸鱼只做点到点跳跃；不来回折返。
3. **主题和素材先统一**：同一主题、干净 demo 数据、同一裁切比例；宁可少展示一个功能，也不混主题。

## 1. 流程（8 步）

### 1）读目标插件

- README / README_ZH 的 Features 表；
- 源码里的 tab、按钮、面板结构；
- 官方截图 / 官方视频 / release notes；
- 记录：每个功能的名字、入口、点击后的结果、真实界面长什么样。

产出：一张「功能 → 入口 → 结果」表。

### 2）定分镜（先文字，后动画）

固定五段式（28s 版本）：

| 段 | 时间 | 内容 |
| --- | --- | --- |
| 开场 | 0–5s | 终端输入 `dsh` → 像素鲸鱼拼合 → 喷水 |
| 进入 DSH | 5–9s | Dock 三跳（文件/Git/DSH）→ DSH 窗口展开 |
| 找插件 | 9–12s | DSH 主界面正面 → 跳到「插件」→ 插件页 |
| 安装 | 12–15s | 搜索 → 结果卡 → 安装 → 蓝色进度 → 已安装 |
| 功能 | 15–26s | 统一侧栏壳，鲸鱼沿 tab 逐个点开 |
| 片尾 | 26–28s | 黑底片尾 + 安装命令 + 鲸鱼右上角 |

### 3）收素材

- **同一主题**：要么全浅色，要么全深色；
- **干净数据**：demo workspace，不能出现真实对话、个人路径、账号；
- **裁切**：只取插件侧栏/面板区域，不塞整窗截图；
- **来源**：优先官方仓库截图；没有的再自己截，不用深色截图硬凑浅色。

### 4）搭统一视觉壳

- 固定的侧栏壳：标题、tab 栏、面板卡片、右侧 3 条短文案；
- 鲸鱼尺寸统一（56px）；
- 页卡标题统一格式：`01 / 文件树 + 搜索`；
- 面板切换只用淡入/上移，不用闪白、硬切。

### 5）设计鲸鱼运动

- 起点、终点都落在**同一个视觉基准线**上（tab 栏或面板同一条线）；
- 每个功能只做一次「跳 tab → 按下」；需要展示结果时，跳一次面板内固定点，然后沿原路回 tab 栏；
- 不允许「tab → 面板左下 → 下一个 tab → 面板右下」这种折返；
- 片尾从最后一个 tab 直接跳到画面右上角。

### 6）相机

- DSH 窗口打开后，只做一次「低机位 → 正面」的抬升；
- 功能段保持正面，不再额外推拉/跳切；
- 转场优先用内容滑入（例如侧栏从右滑入），不要硬换场景。

### 7）渲染

- Onetake 自定义 comp（Three.js + canvas UI），1920×1080 / 30fps；
- 运动模糊：shutter 180°；
- 4 workers 并行；渲染后抽帧检查（每个 tab 的落点、点击帧、片尾帧）。

### 8）声音

- BGM 铺底 + 动作音效：键盘、拼合、落地、窗口、whoosh、点击、结果、安装完成、片尾；
- 事件按帧写时间线（30fps）；
- 混音目标：RMS ≈ -18.5 dBFS，peak ≈ -1.0 dBFS；
- AAC 256k 封装，音画同长。

## 2. 分镜模板（可复用）

```text
0–5s    终端 dsh → 鲸鱼拼合 → 喷水
5–9s    Dock 三跳 → DSH 窗口展开
9–12s   DSH 正面 → 跳到「插件」→ 插件页
12–15s  搜索 → 结果卡 → 安装（蓝色）→ 已安装
15–16s  侧栏从右滑入，tab 栏出现
16–19s  功能 1：tab → 结果 1
19–22s  功能 2：tab → 结果 2
22–24.5s 功能 3：tab → 结果 3
24.5–26s 功能 4：tab → 结果 4
26–28s  黑底片尾 + 安装命令 + 鲸鱼右上角
```

每个功能固定 4 拍：

| 拍 | 时长 | 画面 |
| --- | --- | --- |
| 聚焦 | 0.6s | tab 高亮 |
| 点击 | 0.4s | 鲸鱼落下 + 波纹 |
| 结果 | 1.2s | 面板切换/内容展开 |
| 停留 | 0.8s | 页卡标题出现 |

---

## 3. 素材规范

- 截图：至少 2x，PNG；裁切后宽度 ≥ 600px；
- 主题：同一套（浅色/深色）；
- 数据：demo workspace、demo 分支、无个人内容；
- 命名：`<plugin>-<feature>-<state>.png`；
- 版权：截图来源 + license 写进 case 文档。

---

## 4. 视觉与运动规范

- 鲸鱼：56px，阴影 30px，点击波纹 40px；
- 侧栏壳：浅色 `#f7f8fb`，圆角 18，边框 `#e6eaf1`；
- 主色：`#2f6bff`；强调文字：`#9cf6ff`；
- tab：当前项蓝底白字，其余白底灰字；
- 页卡标题：40px 标题 + 28px 三条短文案；
- 相机：正面 `p(5.5, 9.2, 3.6)` 看 `(5.5, 0.1, -0.5)`，fov 40；
- 禁止：闪白转场、无意义推拉、鲸鱼折返、tab 重复。

---

## 5. QA 清单

- [ ] 每个 tab 的鲸鱼落点都在 tab 中心；
- [ ] 每次点击都有波纹/按压反馈；
- [ ] 面板切换和鲸鱼落点同帧；
- [ ] 转场没有硬切/黑闪；
- [ ] 片尾能读清插件名 + 安装命令；
- [ ] 音频峰值 ≤ -1 dBFS，无削波；
- [ ] 全片 ≤ 30s；
- [ ] 无个人内容、无未授权素材。

---

## 6. 踩过的坑

| 问题 | 原因 | 解法 |
| --- | --- | --- |
| canvas 截图纹理全黑 | file:// 图片污染 canvas | 图片转 base64 data URL |
| 面板切换不更新 | canvas 缓存 key 没带状态 | key 加入 tab/结果/进度 |
| 相机/鲸鱼乱跳 | 关键帧/跳跃数组没排序 | 排序后按时间取最后一个已完成 |
| 功能段很乱 | 混主题、整窗截图、tab 重复 | 统一浅色 + 裁侧栏 + 单 tab 栏 |
| 前后接缝冲突 | 硬换场景 | 侧栏从右滑入，旧画面保留到盖住 |
| 鲸鱼折返 | 每个功能都跳面板左右侧 | 只沿 tab 栏单向移动 |
| 任务/侧聊截图带个人内容 | 官方截图是作者真实会话 | 只用于内部参考，公开片用干净页卡或重截 |

---

## 7. 复用到新插件

1. 填「功能 → 入口 → 结果」表；
2. 按模板改分镜时间；
3. 收同主题干净截图；
4. 替换侧栏壳里的 tab 名/面板图/右侧文案；
5. 重设鲸鱼跳跃坐标（统一基准线）；
6. 重写音频事件时间线；
7. 渲染 1080p、抽帧、混音、QA。
